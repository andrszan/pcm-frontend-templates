# 项目使用前置环境准备

本文档说明当前项目的使用方式。历史搭建过程见 [项目架构搭建说明文档](项目架构搭建说明文档.md)。

## 运行环境

- Node.js `>= 22.22.2`
- pnpm `11.17.0`（由根目录 `package.json` 的 `packageManager` 字段固定）

建议使用 Corepack 管理 pnpm：

```bash
corepack enable
node --version
pnpm --version
```

不要使用 `pnpm@latest`、npm、Yarn 或 Bun 安装本项目依赖；它们不受当前锁文件与 package manager 契约约束。

## 安装并启动

```bash
pnpm install
cp .env.example .env.local
pnpm dev
```

`NEXT_PUBLIC_API_URL` 留空时，Axios 会请求当前站点的相对路径。本地联调本机后端时，还需在 `next.config.ts` 配置 `rewrites`，说明与示例见根目录 [README.md](../README.md)「环境变量」。所有 `NEXT_PUBLIC_` 变量都会暴露到浏览器，不能填写 Token、密码、API Key 或其他敏感信息。

## 本地验证

```bash
pnpm type-check
pnpm lint
pnpm test:run
pnpm build
pnpm exec playwright install chromium
pnpm test:e2e
```

`pnpm test` 是 watch 模式，仅用于本地开发时持续执行；验证时使用 `pnpm test:run`。

## 更新依赖或组件

锁文件是当前已验证依赖组合的一部分。不要在项目初始化时执行 `pnpm update --latest`，也不要执行 `shadcn add --all --overwrite`。

需要新增或更新某个 shadcn/ui 组件时，先确认具体需求，再通过 `components.json` 的现有配置按组件执行命令，并审查生成的 diff。`src/components/ui/` 由 shadcn 生成，非必要不直接手改。
