## 前置环境准备

> 在使用本项目前，需要执行的操作。


### 1. 检查和安装 Node.js（推荐 Node 20.19 + LTS）

**使用 fnm（推荐）**

```bash
# macOS/Linux
curl -fsSL https://fnm.vercel.app/install | bash

# Windows (PowerShell)
winget install Schniz.fnm

# 验证并设置
fnm install 20
fnm use 20
fnm default 20
node --version  # 验证 >= v20.19.x
```


### 2. 安装/验证 pnpm（>= 9.x）

```bash
# 启用 corepack（Node.js 内置）
corepack enable

# 安装最新 pnpm
corepack prepare pnpm@latest --activate

# 验证
pnpm --version  # 应该 >= 9.x

# 配置全局环境（Windows/macOS/Linux）
pnpm setup

# Windows: 重新加载环境变量
refreshenv
# 或关闭终端重新打开
```


### 3. 验证其他工具

```bash
# Git（>= 2.40）
git --version

# 验证 npm 已禁用（推荐使用 pnpm）
npm -v  # 可能存在，但项目中不使用
```


### 4. 更新 shadcn/ui 核心组件

```bash
pnpm dlx shadcn@latest add --all --yes --overwrite
```


### 5. 更新业务核心依赖

```bash
pnpm update zustand @tanstack/react-query @tanstack/react-table axios zod react-hook-form @hookform/resolvers next-themes --latest
```



### 6. 更新开发测试工具链

```bash
pnpm update -D vitest @vitest/ui @vitest/coverage-v8 @vitejs/plugin-react jsdom vite-tsconfig-paths @testing-library/react @testing-library/dom @testing-library/jest-dom @testing-library/user-event @playwright/test --latest

# playwright/test包已经装了，下面这步才是必须的——下载浏览器二进制，默认的话会装3个web浏览器（chromium，firefox，webkit），我们指定只要chromium
pnpm exec playwright install chromium
```

### 7. 重新加载 claude 的插件和技能

```bash
claude /reload-plugins

claude /reload-skills
```
