# 视觉表达与实现能力

## 组件与图标

- 主动复用本地 shadcn 和共享组合：空态 `Empty`、加载 `Skeleton`/`Spinner`、状态 `Badge`/Toggle、低频操作菜单，按任务与本地 API 选择；不因不熟悉而手写简化替代或重复下载。
- 借鉴推荐组合，补齐真实内容、操作和状态，不原样交付示例数据、演示行为或品牌。图标遵循 `components.json` 的 `iconLibrary` 和既有体系，未选择时默认 `lucide-react`；不混用风格或覆盖组件已管理的尺寸、位置。
- 用语义色、浅色底板、填充和层级强化图标识别，不限于单色；遵循现有 UI 颜色规则，优先 variant 和 token，统一重复状态表达，不为局部装饰改全局主题。

## 动效

- 主动为按钮、选中状态、浮层、加载和布局变化采用有收益的动效，表达反馈与空间关系；不默认省略，也不强制每页装饰动画。
- 简单变化优先 Tailwind transition，旋转用 Spinner 或 `animate-spin`；复用已有动画，不重复叠加开合效果或手写已有 Skeleton 的替代品。更多 CSS 动效可评估兼容的 `tailwind-animations`，React 布局、退出或协调动画可评估 Motion，不预装重叠动画库。
- 动效快速、克制、可中断，优先 transform/opacity，避免无意义持续运动、长串逐项入场及阻塞操作，检查布局跳动与性能。遵循 `prefers-reduced-motion`，通过 `motion-reduce`、`motion-safe` 或库能力降级后仍保留加载文案和状态反馈。

## 媒体与依赖

- 主动评估图片、插画、SVG、图表对识别、理解、产品展示、品牌和空态的价值；适用时实际获取或制作并接入，不只提建议，无收益不强制配图。图表服务真实判断并使用可用的可视化指导，不伪造统计；SVG 有明确用途，不在业务组件堆装饰路径。
- 使用可用的 `media-assets` 获取和固化媒体，遵循授权及凭据边界；检查许可、内容、尺寸、裁剪、体积、替代文本和缺失表现，不交付临时外链、私有配置或无关素材。
- 已确认需求缺必要依赖时，按项目 package manager 补充并同步 lockfile；先核对已有替代、兼容性、许可、维护和体积，再验证接入。不因未安装而降低设计，不为未来假设预装。
- 替换全局设计系统、主题等高影响变更仍需按项目边界确认；新增普通依赖不授权升级整个技术栈。客户端边界、服务端渲染和路由遵循目标模板规则。
