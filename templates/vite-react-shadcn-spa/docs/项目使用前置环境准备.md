# 项目使用前置环境准备

本文档说明当前项目的使用和维护方式；版本、脚本和依赖以根目录 [package.json](../package.json) 为准。

## 运行环境

- Node.js `^22.22.2 || ^24.15.0 || >=26.0.0`
- pnpm `11.17.0`

```bash
corepack enable
node --version
pnpm --version
```

不要使用 npm、Yarn 或 Bun 改写锁文件；当前项目只维护 pnpm 安装方式。

## 安装并启动

```bash
pnpm install
cp .env.example .env.local
pnpm dev
```

`VITE_API_URL` 留空时，Axios 在浏览器中请求当前站点的相对路径。本地联调本机后端时，还需在 `vite.config.ts` 配置 `server.proxy`，说明与示例见根目录 [README.md](../README.md)「环境变量」。所有 `VITE_` 变量都会暴露到浏览器，不能填写 Token、密码、API Key 或其他敏感信息。

## 本地验证

```bash
pnpm type-check
pnpm lint
pnpm test:run
pnpm build
pnpm exec playwright install chromium
pnpm test:e2e
```

`pnpm test` 是 watch 模式，`pnpm test:ui` 提供交互式测试界面，`pnpm test:coverage` 生成覆盖率；一次性验证使用 `pnpm test:run`。端到端测试会启动隔离的 Vite 开发服务器，不执行 production build；生产构建由 `pnpm build` 单独验证。

## 更新依赖或组件

锁文件是已验证依赖组合的一部分。不要在项目初始化时执行 `pnpm update --latest`。

需要新增或更新 shadcn/ui 组件时，通过 [components.json](../components.json) 的现有配置按组件执行：

```bash
pnpm dlx shadcn@latest add <component>
```

更新前检查 dry-run 和 diff；不要执行未经审查的全量覆盖。`src/components/ui/` 是生成源码，基础设施检查有意避免批量重排它，但 TypeScript 仍会检查其类型。

## 静态部署

构建产物位于 `dist/`。生产静态宿主必须把未知页面路径回退到 `/index.html`，否则直接访问或刷新嵌套路由会返回服务器 404；缺失的真实静态资源仍应保持 404。
